### 先読みと配置

先読みが0命中だった2入力では、ルーター528回と576回のうち504回と552回で候補のGate先頭ページがすでにRAMにあり、各21回が全層共通のバックオフに該当した。初回は履歴がなく、残る各2回の予測は実際の上位4に入らなかった。予測の第1候補そのものはそれぞれ289/527回、289/575回で上位4に入っている。予測候補を増やす余地と、常駐済みの正しい予測に需要I/O削減余地がないことの両方が読み取れる。前段の全外れ対照の中央値は271.3→364.4 ms。需要読み込みは256回のまま、先読みの発行・取消・スロット照合・同期に追加の仕事が生じた。個別の時間配分は未測定。

各層の直近8回で3回以上選ばれた専門家を優先保持する。4回以上滞留し、頻度が1回以下になると通常のLRUに戻る。保持予算は同じ重みキャッシュのうち最大512 MiBで、圧迫時は複数の層をまたいで解放する。2入力のルーター履歴をPythonで独立に再生し、昇降格の対象・方向・判断時点・予算がすべて合った。KVは今回の128位置では全てRAMにあり、Denseには頻度配置を適用しない。
